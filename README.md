# 🧪 LabTestEase

LabTestEase is an Android application developed using **Java** and **Kotlin** that helps users explore laboratories and get assistance regarding lab tests through an integrated AI chatbot.

The application focuses on improving accessibility and user experience in healthcare-related lab services.

---

## 🚀 Features

- 🔍 Explore available laboratories
- ⭐ Display ratings near labs
- 🤖 AI-powered chatbot integration
- 📱 Clean and user-friendly Android UI
- ⚡ Fast and responsive design

---

## 🛠️ Tech Stack

- **Languages:** Java, Kotlin
- **Platform:** Android
- **IDE:** Android Studio
- **Build System:** Gradle
- **Chatbot:** AI-based conversational assistant
